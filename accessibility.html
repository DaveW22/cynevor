Accessibility Statement

Cynevor aims to make its website usable by as many people as possible, including people using assistive technologies and customised display settings.

Last updated: 2 June 2026

At a glance

  • Cynevor is working towards WCAG 2.2 AA as a baseline target
  • The site includes optional accessibility settings
  • Known limitations will be reviewed as the website develops
  • Accessibility feedback is welcome at contact@cynevor.com

Accessibility Commitment

Usable by as many people as possible

Cynevor aims to make its website usable by as many people as possible, including people using screen readers, keyboard navigation, voice control, switch devices, zoom tools, colour adjustments and other assistive technologies.

Target Standard

Working towards WCAG 2.2 AA

Cynevor is working towards WCAG 2.2 AA as the baseline target across public website pages, with selected enhanced improvements where practical, including stronger contrast, visible keyboard focus, reduced motion support, plain-language summaries and user-controlled display settings.

This is a target and improvement approach. It is not a claim that every page has been independently audited or is fully compliant.

What You Should Be Able To Do

Core website tasks and reading support

The public website is intended to support common accessibility needs across content, navigation and forms.

You should be able to:

  • Zoom without content becoming unusable
  • Navigate the site using a keyboard
  • Use skip links to reach main content
  • Understand page structure through headings
  • Read content with sufficient colour contrast
  • Use the contact form with labels and helpful errors
  • Adjust display settings where available
  • Reduce motion through system settings or site settings where available

Accessibility Settings

Optional display controls

The site includes Accessibility settings that allow users to adjust text size, contrast, motion, reading width, spacing and link visibility on their device.

Known Limitations

Areas kept under review

  • Some older pages or components may still be reviewed as the site develops.
  • Some third-party services, if introduced later, may have their own accessibility limitations.
  • The site is early-stage and accessibility will be reviewed as new pages and features are added.

Feedback and Contact

Tell us about accessibility issues

If you find an accessibility issue or need information in a different format, please contact us at contact@cynevor.com. We will review the issue and aim to respond as soon as reasonably possible.

Enforcement and Complaints

Privacy-related requests

If your request relates to data protection or privacy, you may also have rights under UK data protection law, as described in our Privacy Policy.

Technical Approach

How accessibility is considered

  • Semantic HTML
  • Keyboard-friendly navigation
  • Visible focus styles
  • Meaningful alt text
  • Reduced-motion support
  • Colour contrast review
  • Progressive enhancement where practical

Review Process

Ongoing improvement

This statement will be reviewed as the website changes and as new services, ventures or interactive features are added.
